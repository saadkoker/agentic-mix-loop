Agentic Mix Loop: listen

The same 30 seconds twice: the raw multitracks summed flat, and the mix a team of LLM agents built on their own, hill-climbing on a neural audio judge. Code and write-up on GitHub.

Press play, then switch between Flat and Agent mix while it plays (or press Space). Both versions go through the same fixed limiter and are loudness-matched to −14 LUFS over the whole song, exactly as the judge hears them. In these excerpts the flat version is actually 0.2–0.5 dB louder, so any difference you hear is balance, tone and space, not volume. Each excerpt is the 30-second span where the judge's score rose most. Headphones help.
