# songs/

One folder per song project, created by `python mixloop.py import`. Each holds the tracks, the
session chains, agent-written plugins, renders, history and a report, and is its own git repo
(one commit per accepted change).

Nothing in here is committed to this repository: multitracks are usually licensed for practice
use only. Free multitracks to try: https://cambridge-mt.com/ms/mtk/
